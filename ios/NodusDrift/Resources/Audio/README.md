This bank contains 81 newly produced loops: 80 options use documented CC0
originals and radio tuning is original Nodus synthesis. The eight native noise
and binaural generators are unchanged. Exactly 89 options remain.

Run python3 scripts/prepare_audio.py to reconstruct the current MP3s from pinned
sources and recipes, then python3 scripts/audit_audio_bank.py. Full instructions
and per-source licenses, authors, ratings, hashes and byte comparisons are in
docs/AUDIO_REPLACEMENT_2026-10-09.md and docs/rights/replacement-audio/.

Source WAVs and final MP3s are excluded from Git. No original Moodist recording
is downloaded or bundled by the current preparation pipeline. The app works
offline and has no audio export feature.
